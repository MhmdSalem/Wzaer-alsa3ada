# وزير السعادة

سوبر ماركت في فاقوس، الشرقية. الرئيسية للعروض فقط، مع تايمر وسعر قبل وبعد من لوحة التحكم.

```bash
npx prisma db push
npx tsx prisma/seed.ts
npm run dev
```

- المتجر: http://localhost:3001
- لوحة التحكم: http://localhost:3001/admin
- المشرف الافتراضي: `admin@wazir.local` / `saada2026`

للتطبيقات لاحقاً: `GET /api/v1/catalog` و `GET /api/v1/offers`
